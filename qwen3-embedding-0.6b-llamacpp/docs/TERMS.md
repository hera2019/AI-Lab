# 术语对照

- embedding / 语义向量：用一串数字表示一段文字的含义。
- dimension / 维度：向量中数字的个数；本模型默认是 1024。
- cosine similarity / 余弦相似度：比较两个向量方向是否接近，用于排序。
- corpus / 语料库：允许系统搜索的全部文档或段落。
- chunk / 文档块：从长文档切出的短段落，是检索的基本单位。
- retrieval / 检索：根据问题找到最相关的文档块。
- top-k：只取相似度最高的前 k 个结果。
- reranker / 重排模型：对初步检索结果做更精细的二次排序。
- RAG / 检索增强生成：先检索原文，再让聊天模型依据原文回答。
- hallucination / 幻觉：模型在没有可靠依据时仍生成听起来可信的错误内容。

相似度不等于正确率。它只表示在当前向量模型看来，两段文字的语义方向有多接近。正确用法是比较同一查询下候选段落的相对排名。
