# Qwen3-VL-8B + llama.cpp 项目总结

## 项目结论

第二个本地 AI 实验项目已经完成。我们在 Mac Studio M2 Max、32 GB Unified Memory 上，使用官方 `Qwen3-VL-8B-Instruct-GGUF` 的 `Q4_K_M` 主模型、官方多模态 projector、llama.cpp 和 Apple Metal，完成了从最小图片输入到真实票据、视频、API、错误边界、提示鲁棒性和并发压力的完整实验闭环。

这个模型适合本地图片理解、辅助 OCR、视频抽帧理解、结构化预处理和隐私敏感的初步分析；不适合在没有确定性校验和人工复核时独立承担财务票据、关键数字或其他零容错任务。

## 固定环境

- 硬件：Mac Studio，Apple M2 Max，32 GB Unified Memory
- 模型：`Qwen/Qwen3-VL-8B-Instruct-GGUF:Q4_K_M`
- 多模态 projector：官方 Q8_0 mmproj，由 llama.cpp 自动配对
- llama.cpp commit：`0190529ec450659b541ff608449401e68c27d098`
- 后端：Apple Metal
- 模型权重：实验期间保存在项目外统一缓存；项目完成后已删除，研究成果完整保留
- 源码：独立 detached worktree；整个项目未修改现有贡献分支，也未提交或推送 Git 变更

## 最重要的实测结果

### OCR 与票据

- 清晰 OCR 烟雾测试成功；严格字符比较发现 `°C` 与视觉等价单字符 `℃` 的差异。
- 真实日文票据，本地 Qwen 严格关键业务字段为 16/17，端到端约 11.21 秒。
- Apple Vision 原图 OCR 约 0.72 秒并保留了 `TP` 的独立坐标，但曾以高置信度误读日期且未检出表格。
- Apple Vision + 本地 Qwen API 三次结果一致，为 24/27；稳定不等于正确。
- Gemini 3.6 Flash 使用相同材料约 5.47 秒，NFKC 后为 27/27，但没有主动报告 OCR 日期冲突。
- 最可靠的方案仍是：保留原图和原始 OCR，让模型填结构化字段，再由普通程序检查金额、日期、Unicode 和必填字段，最后只让人确认冲突。

### 视觉理解

- Dashboard、流程图、人物计数、画面方向和两个遮挡案例表现良好。
- 合成图中提示注入案例被正确识别并拒绝执行，但单个案例不能证明普遍安全。
- 柱状图曾在正确读取 `Q2=18`、`Q3=15` 后，仍把“是否下降”回答成 `false`。
- 人物照片曾同时输出 `clapping` 和 `pointing_direction=image_right`；显式输出手臂、食指和双手接触状态后才纠正为 `pointing`。
- JSON Schema 保证结构，不保证语义；temperature 0 保证可复现，不保证正确。

### 性能与并发

- 常见单图片结构化请求约 4.4–4.9 秒。
- 4 并发请求全部正确，没有串线或崩溃。
- 并发从 1 增至 4，吞吐仅从 0.220 增至 0.238 req/s，而平均延迟从 4.55 秒增至 16.79 秒。
- 这台机器适合单用户交互或小规模后台队列，不适合期待多路并发带来线性加速。

## 发现与 upstream 价值

- 标准 `llama-cli --single-turn` 在无效或不存在的媒体输入失败时仍返回退出码 0；最小复现、代码路径和 `llama-mtmd-cli` 正确失败的对照已经整理并提交 issue。
- 透明 alpha 行为已用 libmtmd 像素探针直接记录；EXIF 方向属于已知上游限制。
- 其余观察到的数字、动作、OCR 和提示漂移均属于模型答案质量，目前没有证据归因于 llama.cpp/libmtmd。
- 是否实现退出码修复，适合等上游确认 issue 行为设计后再决定，不需要为了“有 PR”仓促改代码。

## 实际使用原则

1. 让模型返回原子事实，例如文字、数字、坐标、是否接触；让普通程序计算趋势、金额和一致性。
2. 同时保存原图、原始 OCR、模型原始响应、校验结果和人工修正，保证可以审计。
3. 对不可见、模糊或遮挡内容明确允许 `UNKNOWN`，不能强迫模型猜答案。
4. 使用生产环境的完整 system prompt、user prompt 和 schema 做固定回归；看似相近的提示可能产生相反答案。
5. 本地模型负责隐私、离线和低成本预处理；高准确率网络模型负责复杂填表；普通程序和人工确认负责最后可信度。

后续只有在以下情况出现时才值得重开：

- llama.cpp 上游回复已提交的 issue，需要补充复现或验证修复。
- Qwen 或 llama.cpp 发布重要新版，需要运行固定回归测试。
- 决定建立独立的 iPhone 小模型或真实票据产品项目。
