| ID | 实际应用意义 | 输入设计 | 主要判定 |
| --- | --- | --- | --- |
| ENV-001 | 确认本机真的使用 GPU | Release + Metal 构建与最小运行 | commit、Metal 日志、无静默 CPU 回退 |
| GEN-001 | 第一张可用本地图 | 固定英文提示、1024×1024、4 steps、固定 seed | 成功 PNG、无全黑/损坏、总耗时 |

| UI-001 | 人可以交互，程序可以调用 | CLI 与内置 Web UI/API 同参数 | 输出和错误语义一致 |

## 评分原则

- 每个质量用例保存原始提示、negative prompt、seed、steps、CFG、尺寸和模型哈希。
- 同时记录模型加载、文字编码、采样、VAE 解码、总墙钟时间、峰值内存和 swap。
- 数量、关系和文字使用客观字段评分；美感只作为单独的主观备注。
- 图片编辑保存输入和输出，并用差异图观察非目标区域是否被误改。
- 框架崩溃、挂死、错误退出码、输入格式误处理或 Metal/CPU 行为不一致，才优先评估为上游工程问题。
