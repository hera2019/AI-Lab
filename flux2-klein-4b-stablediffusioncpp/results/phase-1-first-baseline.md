# Phase 1：第一张可复现基线图

日期：2026-09-03

## 实际应用意义

本测试确认模型能完整理解提示词、在 M2 Max Metal 上执行 4 步扩散采样、通过 VAE 解码并保存有效 PNG。同时用相同 seed 独立运行两次，验证当前软件与模型组合能否作为后续精度、参数和版本对比的稳定基线。

## 固定参数

- 输出：1024 × 1024 RGB PNG
- seed：`260903`
- steps：4
- sampler：Euler
- CFG：1.0
- diffusion flash attention：启用
- offload-to-CPU：启用
- stable-diffusion.cpp：`6b3edaaf32cc19e5bb2d819c788bd557eddc8eba`
- Metal：`MTL0 / Apple M2 Max`

提示词保存在 `results/generated/phase-1-baseline/flux2-klein-4b-seed-260903-prompt.txt`。

## 性能

| 指标 | 首次运行 | 同 seed 重复 |
| --- | ---: | ---: |
| 文字条件计算 | 5.08 秒 | 2.76 秒 |
| 4 steps 采样 | 46.99 秒 | 44.03 秒 |
| VAE 解码 | 8.25 秒 | 7.95 秒 |
| 模型报告总生成 | 60.36 秒 | 54.78 秒 |
| 实际墙钟时间 | 61.07 秒 | 55.42 秒 |
| 最大常驻内存 | 8,508,260,352 字节 | 8,659,599,360 字节 |
| 运行期间 swaps | 0 | 0 |

第二次更快主要来自操作系统文件缓存与首次初始化之后的热状态；单独启动的新进程仍会加载 Metal 内核和模型。

## 可复现性

两张图片均为 2,755,354 字节，二进制逐字节相同：

```text
902d78de87db7b42bf211bc27c5a0c6cc2c0a3d28134bbb167a7572399cf79dd
```

结论：在本机当前配置下，同 prompt、seed、尺寸、采样器、steps、模型权重和 commit 得到完全一致的 PNG。

## 人工检查

- 通过：雨夜东京街道、拉面小店、冷暖光线、湿地反射与摄影感。
- 通过：一辆红色自行车位于画面左侧。
- 部分通过：蓝色陶瓷猫位于柜台，但模型额外生成了一只白猫。
- 失败：要求正好三盏纸灯笼，实际生成五盏。
- 失败：要求招牌写 `AI LAB`，实际生成 `AI LLAB`。

结论：Q4_0 的整体视觉质量很好，但“画面好看”不等于严格遵循数量和文字要求。这与模型卡对文字渲染及提示遵循边界的提醒一致，值得在 Phase 2 单独测试。
