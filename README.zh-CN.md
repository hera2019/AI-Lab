# AI Lab

在一台 32 GB 的 Apple Silicon 机器上，对七类本地推理模型做的系统性研究。

这**不是模型演示集合**。每一项研究回答同样的三个问题：

> **这个模型能不能进产品？代价是多少？它会怎么坏？**

七项做完之后，反复出现的其实是同一件事：
**搞清楚一个「通过」的结果到底没有证明什么。** 见[「通过」不能证明什么](#通过不能证明什么)。

*[English version](README.md)*

---

## 方法

1. **先写测试计划。**每项研究从一份带验收标准的计划开始，然后才下载模型。
2. **每个结果两份输出。**人读的报告（`.md`）与机器读的指标（`.json`）——任何数字都能重新推算，而不是只能相信。
3. **「跑通」与「通过」严格分开。**链路能跑，绝不写成质量结论。
4. **负面与未决结论保留原样。**不在知道答案之后回头美化；被推翻的结论连同失效原因一起留着。
5. **可复现是设计出来的。**固定 revision、SHA-256 校验、固定 seed。模型权重不进仓库。

## 一个有代表性的发现

**克隆语音听起来是对的。它只是没把话说全。**

一段 60 秒的声音克隆测试，产出的音频自然、节奏正常、能听出是对的说话人。它同时漏掉了原文中间的 40 个字。

没有人能听出来——因为跳过之后读出的仍是一句通顺的话，只是不是原文那句话。

它是靠**不相信试听结果**发现的：把生成音频用两套独立的 ASR 转写回文字，与原文比对。两套都指向同一处，排除了识别错误；缺口在中间而结尾完整，排除了截断。

原因在文本里。短语「我现在说……」在这段话里出现了三次。模型读完第一处之后，从第三处继续——这是自回归模型在重复 n-gram 上的文本—语音对齐串行，就像人朗读时眼睛跳到了下面相似的一行。

由此产生三个结果：

- **一个假设死了。**模型并非「只能生成约 35 秒」——它读到了最后一个字。生成长度从来不是限制，**对齐稳定性才是**。
- **一条工程规范取代了它。**逐句生成，且每段产出都必须回读转写核对。两者缺一不可。
- **一类风险有了名字。**这是**静默失败**：没有报错、没有杂音、音频没有断口。它无法靠试听发现，只能靠交叉核验——这正是回读校验存在的全部理由。

完整记录：[`phase-1-iphone-repeat-verification.md`](qwen3-tts-0.6b-voice-clone-mlx/results/phase-1-iphone-repeat-verification.md)

## 「通过」不能证明什么

同一种形状的错误在不同领域反复出现。收在这里，因为这个模式比任何单个数字都有用：

| 领域 | 诱人的结论 | 它实际证明了什么 |
|---|---|---|
| 语音合成 | 程序没报错就跑完了 | 与声音是否可用无关 |
| 语音合成 | 听起来就是那个人 | 与内容是否完整无关 |
| 语音识别 | 输出了通顺的文字 | 什么也没证明——静音也会输出通顺文字 |
| 票据 OCR | 三次运行结果完全一致 | 与正确性无关；它是稳定地错 |
| 声音克隆 | 回读转写出来的字是对的 | 与音色像不像无关 |
| 说话轮次 | 轮次切分正确 | 与那些人**是谁**无关 |

上面每一条，都是靠**造一个有可能推翻结果的检查**才得到的——第二套 ASR、逐字段的严格真值、熟悉说话者的听者。**那个检查本身，才是真正的产出。**

## 硬件与环境

| | |
|---|---|
| 机器 | Mac Studio · Apple M2 Max · 32 GB Unified Memory |
| 系统 | macOS 26.6.2, arm64 |
| 推理框架 | llama.cpp · whisper.cpp · stable-diffusion.cpp · MLX / MLX-Audio |
| 加速 | Apple Metal, Apple Accelerate |

全部离线运行。这些研究中没有任何一次推理依赖网络服务。

模型权重**不在**本仓库——由每项研究的 `scripts/download_*` 下载到独立目录，固定 revision 并做 SHA-256 校验。数个项目在完成后删除了权重；记录不依赖权重也完整。

## 伦理与隐私

本仓库同时包含语音识别与语音合成（含声音克隆）的研究。这个组合需要一条明确的边界。

- **不发布任何真人录音**——包括作者本人的。把录音和克隆工具一起发布，等于同时提供声纹样本和方法，因此整类排除，不论内容是否敏感。
- 发布的音频素材全部是**合成的**，由 `macOS say` + FFmpeg 生成，并在 [`manifest.json`](whisper-large-v3-turbo-whispercpp/tests/fixtures/audio/manifest.json) 中如实标注。
- 声音克隆的授权检查写在代码里，不是写在文档里：[`clone_voice.py`](qwen3-tts-0.6b-voice-clone-mlx/scripts/clone_voice.py) 不加 `--consent-confirmed` 直接拒绝运行，每个结果的元数据都带 `synthetic_audio: true` 与 `consent` 字段。
- 作者本人录音的逐字稿在公开前由 [`tools/redact_for_publication.py`](tools/redact_for_publication.py) 脱敏。全部客观指标——时长、采样率、RTF、内存、seed、SHA-256——原样保留，因此没有任何结论依赖被脱敏的文本。

生成的音频从不冒充真人。

## 怎么读这个仓库

每项研究自成一体，结构一致：

```
<研究>/
├── README.md          目标、边界、当前状态
├── docs/NN-plan.md    先写的测试计划
├── results/
│   ├── phase-N.md     结论，含主观检查项
│   ├── phase-N.json   原始指标
│   └── phase-N.log    完整运行输出
├── scripts/           可运行，用环境变量参数化
└── tests/fixtures/    带 manifest 的合成测试素材
```

如果只看一份，看[声音克隆的核验记录](qwen3-tts-0.6b-voice-clone-mlx/results/phase-1-iphone-repeat-verification.md)——它是这些研究工作方式最短的一个完整样本：一个怀疑，一个有可能推翻它的交叉核验，一个定位到的根因，以及由此得出的一条规范。
