# Phase 1 · iPhone 自然语音同文对照

## 实际意义

让本人原录音与克隆语音说同一段文字，并将两者对齐到相同响度，可减少文字内容和音量造成的判断偏差，集中比较音色、语速、停顿、语气和发音位置。

这是一项偏容易的“同文复述”测试：它适合判断模仿能力，但不能单独证明模型能用该声音自然地朗读从未出现过的新文字。

## 输入

- 来源：iPhone“语音备忘录”
- 原始格式：AAC / 48 kHz / 单声道 M4A
- 原始时长：60.224 秒
- 模型输入：本地转换的 24 kHz / 单声道 / PCM 16-bit WAV
- 模型输入时长：60.160 秒
- 文字稿来源：macOS“语音备忘录”本机转写，仅整理标点和段落，保留其识别出的用词
- 授权：说话者本人明确同意

原始录音、模型输入 WAV 和准确文字稿均放在 `private/reference/`，并由 `.gitignore` 排除。

## 生成设置

- 模型：Qwen3-TTS-12Hz-0.6B-Base-bf16（MLX）
- 语言：Chinese
- seed：260906
- 参考文字与目标文字：完全相同
- 运行方式：Apple Metal，本地离线生成

## 客观结果

| 项目 | 结果 |
| --- | ---: |
| 原声时长 | 60.160 秒 |
| 克隆时长 | 35.650 秒 |
| 模型加载 | 3.562 秒 |
| 生成计算 | 30.024 秒 |
| 标准 RTF | 0.842 |
| 生成速度 | 1.187× 实时 |
| MLX 峰值内存 | 10,108,471,853 bytes（约 9.41 GiB） |
| swap | 0 |

> ⚠️ **本节的语速推断已于 2026-09-08 被修正。**下面这段原文保留，但其前提「目标文字确实完整读出」已被推翻。
> 实测确认克隆语音跳过了中间连续 40 个字符，因此 1.69× 并非真实语速比。
> **修正值为 1.404×**（克隆 4.993 字/秒 vs 原声 3.557 字/秒）。
> 完整核验、跳句位置与成因见 [`phase-1-iphone-repeat-verification.md`](phase-1-iphone-repeat-verification.md)。

在目标文字确实完整读出的前提下，克隆语音只用了原声约 59.26% 的时间，相当于约 1.69 倍的说话速度。是否有漏读或改词需要通过试听确认，不能仅凭时长判定。

## 公平试听文件

- `results/generated/phase-1-iphone-original-loudness-matched.wav`：本人原声，-20.0 LUFS
- `results/generated/phase-1-iphone-repeat-loudness-matched.wav`：克隆声，-20.0 LUFS
- `results/generated/phase-1-iphone-original-then-clone-matched.wav`：原声 → 1.5 秒静音 → 克隆声

两段均为 24 kHz、单声道 PCM WAV。原声音量动态范围为 4.2 LU，克隆为 2.8 LU；克隆的响度变化更小，可能主观上显得更平。

## 主观检查

> ✅ **已于 2026-09-08 完成回填**，结果见 [`phase-1-iphone-repeat-verification.md`](phase-1-iphone-repeat-verification.md) 第 4 节。
> 摘要：**相似度较高**；家人在 A/B 对照下可认出同一人，主要差异是感知年龄偏年轻与部分尾音；本人认为差异主要来自语速。
> 第一项「是否完整读出相同文字」的答案是 **否** —— 中间跳过 40 字符。

原始清单（待本人及熟悉声音的家人填写）：

- [ ] 是否完整读出相同文字，有无漏读、改词或重复
- [ ] 音色是否像
- [ ] 发音位置与咬字是否像
- [ ] 语速是否像
- [ ] 句内停顿是否像
- [ ] 语气和情绪起伏是否像
- [ ] 只听克隆声时，能否可靠认出说话者

## 技术结论

生成链路成功，模型在 M2 Max 上可快于实时完成长段中文声音克隆，且未发生 swap。相似度结论必须等盲听或熟悉说话者的家人评价后再写；当前不能仅因程序成功就宣称“克隆通过”。

> **2026-09-08 追加**：上面这句「不能仅因程序成功就宣称克隆通过」的纪律，在本次核验中被证明是对的，而且比预想的更重要——
> 程序成功、音色像、听感自然，**但内容少读了 40 个字**。
> 跳过的那一段在听感上完全连贯，人耳听不出异常。
> **声音听起来像，不代表内容完整。**详见 [`phase-1-iphone-repeat-verification.md`](phase-1-iphone-repeat-verification.md)。

运行时出现 MLX-Audio/Transformers 的模型类型提示，但没有阻断加载或生成。本次输入输出及性能数据均已完整保存。
