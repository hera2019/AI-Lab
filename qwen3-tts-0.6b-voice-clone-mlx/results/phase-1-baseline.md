# Phase 1：旧录音中文声音克隆基线

日期：2026-09-06（Asia/Tokyo）

## 实际意义

这次基线首先验证整条本地链路是否成立：读取本人参考录音、提取音色条件、根据新文字生成语音、保存 WAV，并记录速度和内存。它不是最终音质结论。

## 输入

- 参考音频：`private/reference/legacy-whisper-utterance-7.wav`
- 来源：此前 Whisper 麦克风测试中的本人录音
- 时长：2.624 秒
- 格式：16kHz、单声道、PCM 16-bit
- 平均音量：约 −41.0 dB
- 峰值：约 −23.3 dB
- 参考文字：`这个软件什么都能听得懂啊`
- 目标文字：`你好，这是一次完全在本地完成的声音克隆实验。这句话从来没有在参考录音里出现过。`

参考录音明显偏轻，而且逐字稿来自本地 ASR；因此它更像低质量输入边界样本。

## 输出和性能

- 输出：`results/generated/phase-1-baseline-zh-synthetic.wav`
- 格式：24kHz、单声道、PCM 16-bit
- 音频时长：8.000 秒
- 模型加载：4.023 秒
- 生成：8.182 秒
- 完整 Python 进程：12.207 秒
- 标准 RTF：1.023，即大致实时速度
- 实时倍速：0.978×
- MLX 峰值分配：6,629,313,955 bytes，约 6.17 GiB
- 进程最大常驻内存：2,661,154,816 bytes，约 2.48 GiB
- swap：0

Transformers 在加载时打印了一条 checkpoint 类型提示，但 MLX-Audio 随后成功加载语音 tokenizer、生成有效 WAV 并以状态 0 结束。该提示记录为非阻塞警告。

## 当前结论

技术链路：PASS。

内容正确性和音色相似度：人工意见不一致。本人初听认为很像；长期熟悉本人外放声音的配偶认为不像，并明确指出语气、语速、发音部位和音色均不同。后者更熟悉本人通过空气传播的日常声音，因此本项目采用较严格结论：声音相似度尚未通过，不能把“技术链路成功”写成“高质量克隆成功”。此前 Whisper 大模型已按旧项目清理计划删除，因此本阶段没有为自动回读重新下载模型。

正式质量测试应运行 `scripts/record_reference.sh`，用正常音量录制固定 15 秒文字，再运行 `scripts/run_phase_1_clean.sh` 生成对照。
