# Qwen3-TTS 0.6B Voice Clone · MLX

**研究页面（英文）：**[houjun.dev/lab/voice](https://houjun.dev/lab/voice/)

完全本地的 Apple Silicon 声音克隆实验。只使用本人录音或已获得明确授权的声音。

## 目标

- Qwen3-TTS-12Hz-0.6B-Base
- MLX-Audio / Apple Metal
- 中文零样本声音克隆
- 比较 3 秒、10 秒和约 30 秒参考录音
- 同一音色的中文、日文和英文生成
- 测量首次生成时间、后续生成时间、RTF 和内存
- 检查音色、发音、停顿、语气与噪声复制
- 为以后的视频配音与字幕流水线保留接口

## 隐私边界

`private/` 保存个人参考录音和准确文字，`results/generated/` 保存克隆语音；两者都被 `.gitignore` 排除。不要把未经允许的声音放入本项目，也不要用生成结果冒充真人。

## 当前阶段

Phase 0 已完成：隔离环境、Metal 验证、固定 revision 模型下载和 SHA-256 校验均通过。

Phase 1 旧录音基线已完成。本人初听认为相似，但熟悉本人日常声音的配偶认为语气、语速、发音位置和音色均不像，因此当时的严格结论是声音相似度尚未通过。**该结论仅适用于旧录音基线**；改用 60 秒 iPhone 自然录音后的结果见下一段。

随后从 Whisper 项目找回了固定朗读稿对应的 8.826 秒本人录音，并以相同目标文字和 seed 生成第二版。响度统一后的 A/B 盲听文件和记录表见 `results/phase-1-blind-listening.md`。

现已加入一段 60.224 秒的 iPhone“语音备忘录”自然说话录音，并完成“原话复述”同文对照。模型生成 35.650 秒音频，用时 30.024 秒，标准 RTF 为 0.842，未发生 swap。原声和克隆声已精确对齐到 -20.0 LUFS。详见 `results/phase-1-iphone-repeat.md`。

**2026-09-08 核验结论**（详见 `results/phase-1-iphone-repeat-verification.md`）：

- **相似度：较高。**本人认为很像；家人在 A/B 对照下可认出同一人，认为克隆声偏年轻、部分尾音略有不同。相似度结论至此**已通过**——此前的「尚未通过」是评价缺失，不是评价结果。参考音频质量是与旧基线拉开差距的主要因素。
- **⚠️ 但内容不完整。**经本人试听、macOS 语音备忘录转写与 whisper.cpp 本地转写三重独立确认，克隆语音在长文本一次性生成时发生**跳句**，漏掉中间连续 40 个字符（16.8%），其后完整读至结尾。成因是文本中「我现在说……」重复出现三次，模型对齐串行到了后面的相似片段。
- **语速数据修正**：原记「1.69 倍语速」建立在「完整读出」的前提上，该前提已被推翻。修正值为 **1.404×**（克隆 4.993 字/秒 vs 原声 3.557 字/秒）——接近中文有声书的正常朗读语速，参照物则是自然对话语速。
- **本次最重要的结论：声音听起来像，不代表内容完整。**跳过的片段在听感上完全连贯，人耳无法察觉。凡用于视频配音、播客或有声读物，生成后**必须**做一次 ASR 回读校验。
- **下一步**：改为按句切分、逐句生成再合并，并接入 whisper.cpp 回读校验。
