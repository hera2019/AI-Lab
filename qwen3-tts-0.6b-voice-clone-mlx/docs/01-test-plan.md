# 声音克隆测试计划

## 为什么做

Whisper 项目验证的是“声音变成文字”。本项目验证相反方向：“文字加参考音色变成新语音”。两者以后可以组合成转录、翻译、配音和字幕流水线。

## Phase 0：环境和隐私

- 使用项目独立 Python 环境，不修改 Whisper 项目。
- 模型权重统一放在 `AI-Models`，项目只保存脚本、结果和报告。
- 原始参考录音与克隆语音保存在忽略目录中。
- 每个输出都明确标记为合成语音。

## Phase 1：最小可行克隆

- 使用本人约 3 秒中文录音和准确逐字稿。
- 生成一条录音中从未说过的中文句子。
- 记录加载、生成、音频时长、RTF、内存和 swap。
- 人工听辨音色、清晰度、韵律和异常声音。

## Phase 2：参考长度 A/B

- 在录音条件和目标文本不变时，比较约 3 秒、10 秒和 30 秒参考。
- 不把“更像”只归因于长度；同时记录录音音量、噪声、停顿和逐字稿准确性。

## Phase 3：跨语言

- 用同一段中文参考音色分别生成中文、日文和英文。
- 观察音色保持、口音转移、专有名词和数字读法。
- 用 Whisper 回读生成结果，检查内容是否正确；回读正确不代表音色相似。

## Phase 4：边界与工程测试

- 静音、噪声、错误逐字稿、超短录音、长文本和 Unicode 文件名。
- 连续生成的稳定性、首包延迟、总生成速度和内存。
- 明确区分可恢复输入错误与程序失败。

## 后续项目

视频配音与字幕可采用两条入口：

1. 已有文字 → 声音合成 → 时间轴对齐 → 混入视频 → 生成字幕。
2. 原视频语音 → Whisper 转录 → 翻译或改写 → 声音合成 → 对齐并替换音轨 → 输出字幕。

该方向排在声音克隆质量与速度验证之后。
